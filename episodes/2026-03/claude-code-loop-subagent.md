## 核心看点

Claude Code 全新 Loop 功能 + Sub Agent 架构，让 AI 变成可以持续运行长达三天的自动化代理。

### Loop 功能

- **持续运行**：最长可运行 3 天
- **周期性任务**：代码审查、日志扫描、构建错误修复
- **一条命令启动**：`/loop` 即可开启自动化代理

### Sub Agent 架构

- 主 Agent 分配任务给多个 Sub Agent
- 并行处理，效率倍增
- 复杂任务自动拆解执行

### 实战场景

- 手动检查代码合并？交给 AI
- 部署状态监控？交给 AI
- 日志异常扫描？交给 AI
- 构建失败自动修复？交给 AI
