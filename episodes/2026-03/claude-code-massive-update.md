## 核心看点

Claude Code 的几大颠覆性更新，让终端秒变 AI 编程助理。

### 1. BTW（顺便问一下）命令

- 在不打断主任务流的情况下快速获取信息
- 真正的高效多任务处理
- 适用场景：写代码时顺便查文档、确认 API 用法

### 2. 双重自动化引擎

| 功能 | 类型 | 说明 |
|------|------|------|
| `/loop` 命令 | 会话级 | 在当前会话中循环执行任务 |
| 计划任务 | 持久化 | 桌面端定时执行，关闭终端也能运行 |

**实战场景**：
- 定时代码审查
- 每日报告自动生成
- 与 Telegram 联动通知
- 无人值守自动化工作流

### 3. 底层记忆革命

- 全新系统提示词架构
- 结构化记忆规则：**规则 / 事实 → 为什么 → 如何**
- 长期记忆与上下文理解能力显著增强
- 复杂项目中表现更稳定

### 4. 多模态与办公协同

- **语音输入模式**：解放双手
- **Excel 插件**：AI 直接操作电子表格
- **PowerPoint 插件**：AI 生成演示文稿
