# 公开节目同步

```sh
python3 scripts/sync_youtube.py
python3 -m unittest discover -s scripts -p 'test_*.py'
```

需要 Python 3.9+、curl、yt-dlp。只读取公开 metadata，不下载视频、不读取登录 cookie、不使用付费 API。

- YouTube 官方 RSS 提供精确发布时间和简介；频道 Videos 列表提供当前标题、时长与访问状态。
- `latest.json` 保存 RSS 最近一批公开节目（通常 15 条），按发布时间倒序，日期转换为北京时间。首页读取前 6 条。
- 会员专享、私密、待播与正在直播的条目不进入本 feed。
- README 补充缺失档案索引；新节目页只提供来源信息和原简介节选，不冒充完整笔记。已有人工笔记不覆盖。
- 网络错误、错误频道、数据不完整或最新节目倒退时退出报错；不把空列表提交到首页。无数据变化时不改文件。
- 同步后检查 diff、执行测试，再提交推送。首页无需为每期视频重新部署。GitHub raw 的边缘缓存可能造成几分钟延迟。

每日同步由 Codex 的“每日优化大雷主页”任务执行（每天 09:00，北京时间）。该任务在运行环境可用时工作；如果设备离线或凭据失效，应在下次恢复后补跑。RSS 只覆盖近期节目，长期中断后的完整补档需要另行检查频道历史。
